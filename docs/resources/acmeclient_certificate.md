# opnsense_acmeclient_certificate (Resource)

Manages an ACME Client certificate in the OPNsense os-acme-client plugin.

## Example Usage

```terraform
resource "opnsense_acmeclient_account" "example" {
  name  = "letsencrypt-staging"
  email = "admin@example.com"
  ca    = "letsencrypt_test"
}

resource "opnsense_acmeclient_validation" "example" {
  name         = "cloudflare-dns01"
  method       = "dns01"
  dns_service  = "dns_cf"
  dns_cf_token = "replace-with-cloudflare-api-token"
}

resource "opnsense_acmeclient_action" "reload_gui" {
  name = "reload-web-gui"
  type = "configd_restart_gui"
}

resource "opnsense_acmeclient_certificate" "www" {
  name              = "www.example.com"
  account           = opnsense_acmeclient_account.example.id
  validation_method = opnsense_acmeclient_validation.example.id
  key_length        = "key_2048"
  auto_renewal      = true
  renew_interval    = "60"

  alt_names = [
    "example.com",
  ]

  restart_actions = [
    opnsense_acmeclient_action.reload_gui.id,
  ]
}
```

## Schema

### Required

- `account` (String) UUID of the ACME account used to request the certificate.
- `name` (String) Common Name (CN) for the certificate.
- `validation_method` (String) UUID of the ACME validation method used for challenges.

### Optional

- `aliasmode` (String) DNS alias mode (`none`, `automatic`, `domain`, `challenge`). Defaults to `none`.
- `alt_names` (Set of String) Subject Alternative Names (DNS names).
- `auto_renewal` (Boolean) Automatically renew the certificate. Defaults to `true`.
- `challengealias` (String) Challenge alias used when `aliasmode` is `challenge`.
- `description` (String) Optional description for this certificate.
- `domainalias` (String) Domain alias used when `aliasmode` is `domain`.
- `enabled` (Boolean) Enable this certificate. Defaults to `true`.
- `key_length` (String) Private key length or type (`key_2048`, `key_3072`, `key_4096`, `key_ec256`, `key_ec384`). Defaults to `key_2048`.
- `ocsp` (Boolean) Enable OCSP Must-Staple. Defaults to `false`.
- `renew_interval` (String) Days before expiry to attempt renewal. Defaults to `60`.
- `restart_actions` (Set of String) UUIDs of ACME restart actions to run after issuance or renewal.

### Read-Only

- `cert_ref_id` (String) Trust store certificate reference ID after successful issuance (read-only).
- `id` (String) UUID of the ACME certificate.
- `last_update` (String) Timestamp of the last certificate update (read-only).
- `status_code` (String) Last known certificate status code (read-only).
- `status_last_update` (String) Timestamp of the last certificate status update (read-only).
