# opnsense_routing_gateway (Resource)

Manages a System gateway (Routing → Gateways) via the OPNsense `routing` API.

## Example Usage

```terraform
resource "opnsense_routing_gateway" "wan" {
  enabled          = true
  name             = "WAN_GW"
  description      = "Interface WAN Gateway"
  interface        = "wan"
  ip_protocol      = "inet"
  gateway          = "192.0.2.1"
  default_gateway  = true
  far_gateway      = true
  monitor_disable  = true
  priority         = "255"
  weight           = "1"
}

resource "opnsense_routing_gateway" "peer_site" {
  enabled          = true
  name             = "gw-peer"
  interface        = "opt2"
  ip_protocol      = "inet"
  gateway          = "10.0.0.10"
  default_gateway  = false
  far_gateway      = false
  monitor_disable  = true
}
```

## Schema

### Required

- `gateway` (String) Gateway IP address (or `dynamic` when provided by the interface).
- `interface` (String) Interface identifier (e.g. `wan`, `opt1`, `opt2`).
- `name` (String) Gateway name. Changing this forces a new resource.

### Optional

- `default_gateway` (Boolean) Mark this gateway as a default gateway. Defaults to `false`.
- `description` (String) Optional description.
- `enabled` (Boolean) Enable this gateway. Defaults to `true`.
- `far_gateway` (Boolean) Far gateway (gateway outside the interface subnet). Defaults to `false`.
- `force_down` (Boolean) Force the gateway to be considered down. Defaults to `false`.
- `ip_protocol` (String) Address family: `inet` (IPv4) or `inet6` (IPv6). Defaults to `inet`.
- `monitor` (String) Optional monitor IP address.
- `monitor_disable` (Boolean) Disable gateway monitoring. Defaults to `false`.
- `monitor_noroute` (Boolean) Do not create a static route for the monitor IP. Defaults to `false`.
- `priority` (String) Gateway priority (0-255, lower is preferred). Defaults to `255`.
- `weight` (String) Gateway weight for multi-WAN. Defaults to `1`.

### Read-Only

- `id` (String) UUID of the gateway.
