# opnsense_acmeclient_validation (Resource)

Manages an ACME Client validation method in the OPNsense os-acme-client plugin. The schema focuses on DNS-01 with Cloudflare (`dns_cf`); other DNS providers remain available via the OPNsense UI and are preserved on update.

## Example Usage

```terraform
resource "opnsense_acmeclient_validation" "cloudflare" {
  name         = "cloudflare-dns01"
  method       = "dns01"
  dns_service  = "dns_cf"
  dns_cf_token = "replace-with-cloudflare-api-token"
}
```

## Schema

### Required

- `name` (String) Display name for the validation method.

### Optional

- `description` (String) Optional description for this validation method.
- `dns_cf_account_id` (String) Optional Cloudflare account ID.
- `dns_cf_email` (String) Cloudflare account email (Global API Key auth).
- `dns_cf_key` (String, Sensitive) Cloudflare Global API Key (sensitive).
- `dns_cf_token` (String, Sensitive) Cloudflare API token (sensitive). Preferred over Global API Key.
- `dns_cf_zone_id` (String) Optional Cloudflare zone ID to limit token scope.
- `dns_service` (String) DNS-01 provider identifier. Defaults to `dns_cf` (Cloudflare).
- `dns_sleep` (String) Seconds to wait after publishing DNS records before validation.
- `enabled` (Boolean) Enable this validation method. Defaults to `true`.
- `method` (String) Challenge type. Defaults to `dns01`.

### Read-Only

- `id` (String) UUID of the validation method.
